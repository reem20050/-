# workflows/

ה"מנוע" של החקירה — תוכנית מחקר **פרמטרית** וניתנת־להרצה־מחדש שמכריעה אם, ואיך, להפוך סיגנל ML
("תנועה ≥ X בתוך N דקות", ~75% precision) לכסף דרך long straddle, **לכל** נכס/סף/חלון.

## קבצים
- **`research-workflow.md`** — המסמך המרכזי: פרמטריזציה, השאלה המרכזית, התזה הכמותית, פירוק
  ל-20 workstreams + מצבת הסוכנים, המתודולוגיה (fan-out → verify → synthesize), **שערי החלטה
  G1–G8** (go/no-go לפני הון), ו-runbook להרצה מחדש.

## איך משתמשים
1. הגדר `(instrument, X, N, p, side)`.
2. עקוב אחרי ה-runbook (סעיף 6 ב-`research-workflow.md`).
3. עבור דרך שערי G1–G8 — רק מי שעובר את כולם מצדיק הון אמיתי.

## הקשר
התוצרים של **הרצה אחת** של ה-workflow הזה (על זהב $25/120 ונאסד״ק 150/60) יושבים תחת
`../research/` — מסמכי הניתוח, הביבליוגרפיה (`../research/sources.md`), וכלי ה-EV
(`../research/tools/straddle_ev.py`).
